# 04 — Grid Resilience Pivot

**Status:** Working thesis (lab)

## Framing

Behind-the-meter and islandable assets are often treated as **parasitic load** during interconnection review. The same assets, when commissioned with replayable proof, can be argued as **VPP-capable / resilience assets** — if state and SAT history are trustworthy.

## OIDF’s role

OIDF does not operate a VPP. It makes the **commissioning truth** portable:

- Equipment state machine (Procured → Energized class paths)
- Handoff ledger as digital as-built
- Architecture packs for EV depot BTM, hyperscale island, and remote resilient microgrid

## Honesty

This pivot is a **positioning thesis**, not a claim of production VPP certification. Lab lighthouse paths exist in Keel; market claims stay behind evidence.
